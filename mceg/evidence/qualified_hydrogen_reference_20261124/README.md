## The cache experiment is a different claim

A readout-only build preserves all five standard physical tables byte for byte. It shows exactly zero spontaneous RR cooling in the constant-temperature, six-column control. At a column restart, level cooling coefficients are reset but their temperature-cache key is not. The temperature-only early return then prevents rebuilding them. A controlled build removes only that early return, retaining the existing cooling expression, escape factors, cross sections and all convergence guards. RR cooling is restored while the same five population/condition/optical-depth tables remain byte-identical. Do not generalize this constant-T counterexample to the paper's varying-temperature model without a separate test.

The refreshed C23 ledger and the native OU2 ledger are compared at the same selected states and with the same signed grouping. This is a hydrogen operator check, excluding H free-free and all other species. Unmodified C23, readout-only C23, the cache-refresh control and the external OU2 model are explicitly different records.
