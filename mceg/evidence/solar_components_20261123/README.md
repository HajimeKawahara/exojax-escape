# Solar-model component continuation

These immutable experiments support scoped statements, not a completed
solar-atmosphere equivalence claim. The selected target is a solar-composition
proxy; the unpublished author setup has not been recovered.

| Archive | Question and scope |
| --- | --- |
| hydrogen_escape | C23 line/continuum operators, thick H columns, high-shell collision repair, and retained disagreements |
| hydrogen_atom_convergence | Native n15→20 and independent C23 n15→25 controls at fixed blackbody slab conditions |
| metal_components | Independent metal rates/partitions, multilevel derivatives, conditional observer controls, and explicitly missing Fe-Ly-alpha feedback |
| completed_reference_controls | Four actual C23 fixed-temperature/density runs: Fe80/716 and exact atomic pumping; raw outputs, numerical patches, replay and two figures |
| native_integration | Full Fe716/H/He/molecule/overlap two-cell root; separate boundary tests, builds and prospective MCEG checks |

The two figures use **external Cloudy populations at prescribed T and density**.
They are not a native thermal atmosphere or a fit. The spectral plot retains
Zenodo observations, and the profile figure retains the unsolved energy budget.
Full reference local-tolerance, thermal/wind, and native spatial convergence
remain under investigation. A successfully terminated C23 run is not assumed
to be a converged physical reference.

Each archive contains its own source/configuration/provenance records; do not
merge their scopes or source revisions. Existing evidence tags are unchanged.
Full PHOENIX/FITS/SED arrays, observer stellar_reference arrays, executables,
StableHLO and JAX caches are excluded. Retrieval instructions and input hashes
are retained. Atomic data licenses and the observation's CC BY 4.0 attribution
remain with the corresponding source records.
