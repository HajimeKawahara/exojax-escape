Plotting interpretation
-----------------------
The file has 87 rows and three columns, with no header or formal column schema.
We interpret them as wavelength [angstrom], fractional residual flux, and
fractional uncertainty, consistent with their values and the associated paper:
https://arxiv.org/abs/2606.23899v1
The uncertainty confidence level and spectral-order identity are not specified
in this file. Error bars display the supplied third column without asserting
an independently verified confidence level.

Zenodo identifies the file as the phase-averaged H-alpha emission spectrum.
The filename and paper specify orbital phases 0.30-0.45. The paper describes
planet-frame spectra after nightly-master division and stellar-contamination
masking. These processed residuals are not a raw absolute planet/star spectrum.

Changes for display only: wavelength is converted to velocity using
v = c * (wavelength / wavelength_rest - 1), with the same rest wavelength as the model. The default AdbNist H_I entry gives
6564.63215 angstrom in vacuum from the NIST level-energy difference. The optional
Rydberg comparison uses 6564.69606 angstrom. NIST source and conventions:
https://physics.nist.gov/PhysRefData/ASD/Html/lineshelp.html
Residual and uncertainty are multiplied by 100 for percent display or by 1e6
for ppm display. The supplied fluxes and uncertainties are not rescaled or
rebinned; all 87 samples are retained. A fitted velocity offset, when reported,
is applied to the model before observation processing, not to these data.

The original single-phase overlays used a blackbody stellar reference and did
not apply observation processing. The later processed comparisons use phase
spectra, a stellar line reference, nightly-master division, masking, and
coaddition through the declared processing proxy. These comparisons must name
their processing assumptions and any fitted parameters. The proxy is not a
reconstruction of the authors' complete reduction pipeline, and the supplied
uncertainties do not specify a covariance matrix.
