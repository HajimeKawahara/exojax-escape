Plotting interpretation
-----------------------
The file has 87 rows and three columns, with no header or formal column schema.
We interpret them as wavelength [angstrom], fractional residual flux, and
fractional uncertainty, consistent with their values and the associated paper:
https://arxiv.org/abs/2606.23899v1
The uncertainty confidence level and spectral-order identity are not specified
in this file. Error bars display the supplied third column without asserting
an independently verified confidence level.

Zenodo identifies the file as the phase-averaged H-alpha emission spectrum.
The filename and paper specify orbital phases 0.30-0.45. The paper describes
planet-frame spectra after nightly-master division and stellar-contamination
masking. These processed residuals are not a raw absolute planet/star spectrum.

Changes for display only: wavelength is converted to velocity using
v = c * (wavelength / wavelength_rest - 1), with the same AdbHydrogen rest
wavelength as the model (6564.614 angstrom, the representative vacuum value
listed at https://www.sdss4.org/dr12/spectro/spectro_basics/). Residual and uncertainty
are multiplied by 100 for percent display. No fitted velocity offset, amplitude
rescaling, or additional binning is applied. All 87 samples are plotted.

The overlay is qualitative: the model is at a single phase and uses a blackbody
stellar reference; the observed spectrum is phase averaged and processed.
The observation processing has not been applied to the model.
